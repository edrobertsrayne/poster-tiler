Poster Tiler

How to use

  1. Choose your picture using the file button above — a PNG or JPEG export of your artwork works best.
  2. Pick paper and direction. Leave Orientation on Auto unless you know you want tall (Portrait) or wide (Landscape).
  3. Pick a size. Leave it on DPI for the default size, or choose Custom size and type how big you want the finished poster — the other side adjusts itself so your art never stretches.
  4. Press Download PDF, then print every page at 100% / Actual size — never “Fit to page”, or the sheets won’t line up.
  5. Tape the sheets together following the little labels on the preview (top-left sheet is r0c0, next to it r0c1, and so on).

Higher DPI means a smaller but sharper poster; if the Download button stays greyed out, the red message tells you what to fix.
